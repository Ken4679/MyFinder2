# MyFinder (Windows 11 Fluent 极速文件搜索 & 软件管家)

> **轻量 · 极速 · 纯本地 · 绝对只读安全 · 100% 零残留绿色便携**

MyFinder 是一款专为 Windows 11 / 10 打造的现代化本地文件秒搜与已安装软件管理工具。基于 **Windows 11 Fluent Design 2.0 (Mica / 亚克力效果)** 深度定制，体积仅 **~3.5MB**，内存占用仅 **~15MB**，旨在为用户带来如原生系统级般丝滑、安全、干净的使用体验。

---

## 📖 软件使用指南

### 1. 极速全盘/指定目录文件检索
- **即输即搜（< 5ms 响应）**：在顶部搜索框输入文件名、扩展名或关键字，即刻在数十万文件库中秒级定位目标。
- **多维度智能筛选**：
  - **分类过滤**：快速按「应用软件」、「文档资料」、「媒体文件 (图片/视频/音频)」、「代码工程」、「压缩归档」过滤。
  - **高级属性**：支持按文件大小区间（<1MB、1-100MB、>1GB）、修改时间范围、排序方式（相关度/大小/时间/名称）精准查找。
- **原生文件交互**：
  - **双击项目**：调用 Windows 默认程序直接打开文件。
  - **定位所在目录**：点击「打开所在文件夹」或快捷按钮，自动唤起 Windows 资源管理器并高亮选中该文件。
  - **一键复制路径**：点击快捷复制完整物理路径到剪贴板。

### 2. 软件管家 (App Manager)
- **已安装应用全局索引**：自动扫描系统桌面、开始菜单与程序目录中的已安装软件。
- **快速启动与定位**：一键运行应用，或直接定位到其可执行文件与快捷方式所在物理目录。
- **应用卸载辅助**：点击安全呼出 Windows 系统原生「应用和功能」或对应软件自带的官方卸载器，安全规范卸载。

### 3. 主题与界面交互
- **Fluent 2.0 亚克力材质**：完美契合 Windows 11 设计语言，支持无缝亮色 / 暗色主题切换与实时视图密度调节（紧凑列表 / 详情卡片）。

## 🔒 核心安全性承诺（为什么你可以完全放心使用）

在数据安全和系统稳定性上，MyFinder 遵循以下**铁律级别**的设计原则：

1. **绝对只读安全原则（Zero-Destruction Policy）**：
   - 本软件在架构底层**没有编写任何物理修改、重命名、移动或删除磁盘用户文件的代码与接口**。
   - 绝不会发生误删文件、误改扩展名或破坏系统关键目录的意外情况。
   - 所有对文件的实际物理操作（如删除、重命名），均通过唤起 Windows 原生资源管理器（Explorer）由用户亲自操作。
2. **纯本地离线运行（100% Offline & Private）**：
   - 不含任何网络上传、云端遥测或用户行为分析代码；
   - 您的所有文件名、文件路径、搜索记录与软件清单**绝不离开您的计算机**。
3. **无系统提权要求**：
   - 仅以当前普通用户权限运行，不强制申请管理员（UAC）权限，不侵入系统内核。

## 🎒 什么是「便携版 (Portable)」？它的意义是什么？

便携版（Portable Edition，即绿色的 `MyFinder-Portable-2.0.0.exe`）与传统需要安装的软件（Setup Installer）有本质区别：

| 特性维度 | MyFinder 便携版 (Portable) | 传统安装版软件 (Installer) |
| :--- | :--- | :--- |
| **安装过程** | ❌ **无需安装**，下载后双击即可直接运行 | ⚠️ 需要运行安装向导，写入 Program Files |
| **U 盘即插即用** | ✅ **支持**，可放在移动硬盘/U 盘随身携带在任何电脑使用 | ❌ 无法随身携带，换电脑需重新安装 |
| **注册表写入** | ❌ **0 写入**（不污染 Windows 注册表 `HKEY_*`） | ⚠️ 写入大量安装信息、卸载项与启动项 |
| **运行库依赖** | ✅ **0 依赖**（复用 Win10/11 自带的原生 WebView2） | ⚠️ 往往需要额外安装臃肿的运行库 |
| **软件卸载** | ✅ **直接将 `.exe` 移入回收站即彻底卸载** | ⚠️ 需走控制面板卸载，常残留注册表垃圾和空文件夹 |

## 📁 运行时会不会创建文件？创建的话会存放在哪里？

作为一款极致追求「纯粹绿色」的工具，MyFinder 已在底层实现了 **100% 同目录数据闭环隔离**：

### 1. 软件运行时会产生哪些数据？
为了让您在下一次打开时保留偏好设置与索引，软件仅产生极少量的轻量数据：
- **用户偏好设置**：主题（深色/浅色）、视图排版（卡片/列表）以及最近搜索历史（纯本地）；
- **WebView2 渲染缓存与本地索引**（体积仅为数十 KB 到几 MB）。

### 2. 存放位置说明（100% 保存在 EXE 同级目录）
所有的缓存、配置、索引与浏览器运行时数据**全部且唯一存放在 EXE 旁边的 `data` 文件夹内**：
- 📂 **存放路径**：`[EXE所在目录]\data\`
- 🚫 **绝不污染系统**：系统 `%LOCALAPPDATA%`、`%APPDATA%`、注册表、C盘根目录、文档、桌面等**完全为 0 写入、0 生成**！
- 🧳 **真正 U 盘便携**：将整个文件夹拷入 U 盘，插到任何电脑上运行，配置和数据永远跟随该文件夹，拔出即走。

## 🧹 怎么完全删除这个应用（就像从来没有使用过一样）？

得益于 100% 同目录封闭设计，删除该软件**极其简单、毫无负担**：

### 只要 1 步：
直接将 **`MyFinder-Portable-2.0.0.exe` 及其同目录下的 `data` 文件夹（或者它所在的整个文件夹）直接删除并清空回收站** 即可！

> **✨ 真正的 0 残留**：
> - ❌ 不需要去控制面板卸载
> - ❌ 不需要去 AppData 查找并清理残留文件夹
> - ❌ 不需要运行任何清理垃圾软件
> - ❌ 不需要清理注册表
> 
> 删除该文件夹后，**电脑立即彻底恢复初态，没有任何一行代码或一个字节留在您的操作系统中，就像从来没运行过一样**。
